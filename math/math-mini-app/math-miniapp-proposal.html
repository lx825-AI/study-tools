5.2 词法分析器（Tokenizer）

将 LaTeX 字符串拆解为 Token 序列，覆盖 约 40 种 Token 类型。

// src/utils/formula/tokenizer.ts
export enum TokenType {
  // 结构符号
  LBrace, RBrace, Subscript, Superscript,  // { } _ ^
  Frac, Sqrt, Sum, Prod, Int, Lim,         // \frac \sqrt \sum \prod \int \lim
  Left, Right,                              // \left \right
  // 希腊字母（~25 个，大小写）
  Alpha, Beta, Gamma, Delta, Theta, Lambda, Pi, Sigma, Phi, Omega, ...
  // 运算符 & 关系符
  Plus, Minus, Times, Div, Cdot, Pm, Le, Ge, Ne, Approx,
  Infty, Partial, Nabla, Forall, Exists,
  // 函数名
  Sin, Cos, Tan, Ln, Log, Exp, Max, Min, Lim,
  // 矩阵 & 装饰
  Aligned, Pmatrix, Cases, Choose,
  Bar, Hat, Vec, Tilde, Ddot, Underbrace, Overbrace,
  // 文字 & 数字
  Text, Number, Letter, Space, To,
}

Token 覆盖率与实现优先级：

类别Token 命令频率优先级
结构\frac, \sqrt, ^, _极高（几乎所有公式）P0
希腊字母\alpha ~ \Omega（~25 个）高P0
运算符\sum, \int, \lim, \partial, \infty高P0
函数\sin, \cos, \ln, \log, \exp高P0
括号\left(, \right)中P1
矩阵/排列\begin{aligned}, \begin{pmatrix}, \begin{cases}低（~10 条）P1
装饰\vec, \bar, \hat, \dot低P2
特殊\underbrace, \choose极低（2-3 条）P2
策略：P0 覆盖 95% 公式；P1 第二周补全；P2 降级为预渲染图片兜底。

5.4 Canvas 渲染器（Renderer）

核心：measure（计算布局）→ draw（逐节点绘制）两阶段。

// src/utils/formula/renderer.ts
export class FormulaRenderer {
  private metrics: CharMetrics       // 预计算字符宽度表
  private cache = new LRUCache<string, RenderResult>(200)

  // 阶段一：递归计算布局（不绘制）
  measure(node: ASTNode, ctx: CanvasRenderingContext2D, fontSize: number): Box

  // 阶段二：递归绘制
  draw(node: ASTNode, ctx: CanvasRenderingContext2D, box: Box, x: number, y: number): void

  // 统一入口
  render(latex: string, canvas: Canvas, fontSize: number): RenderResult {
    const cacheKey = `${latex}:${fontSize}`
    if (this.cache.has(cacheKey)) return this.cache.get(cacheKey)!
    const ast = parse(tokenize(latex))
    const ctx = canvas.getContext('2d')
    const box = this.measure(ast, ctx, fontSize)
    // 适配设备像素比
    const dpr = uni.getSystemInfoSync().pixelRatio
    canvas.width = box.width * dpr; canvas.height = box.height * dpr
    ctx.scale(dpr, dpr)
    this.draw(ast, ctx, box, 0, box.baseline)
    const result = { width: box.width, height: box.height }
    this.cache.set(cacheKey, result)
    return result
  }
}

6.2 本地优先 + 云端同步策略

核心原则：所有写入先落本地，异步同步到云端。读取先读本地，后台拉取云端增量。

⚡ 写入路径

用户操作 → uni.storage 写入（0ms）→ UI 立即更新 → 后台调用云函数 → 失败加入重试队列 → 网络恢复自动重试

📖 读取路径

页面加载 → 读本地数据（<50ms）→ 立即展示 → 后台拉云端增量 → 合并冲突（最后写入胜出）→ 静默刷新 UI

🔄 增量同步

每条数据维护 updatedAt 时间戳，同步时只传输上次同步之后的变更，减少数据传输量

📴 离线队列

离线操作存入队列（上限 200 条），网络恢复后 FIFO 重放。幂等设计确保重复提交安全

6.3 DataSyncer 同步引擎

// src/services/sync.ts — 核心同步引擎
export class DataSyncer {
  private queue: SyncOp[] = []
  private syncing = false
  private lastSyncAt = '1970-01-01'

  // 写入：本地即时生效 + 加入离线队列
  async write(collection: string, data: any): Promise<void> {
    const localData = { ...data, updatedAt: Date.now(), _synced: false }
    uni.setStorageSync(`sync:${collection}:${data._id}`, localData)
    this.queue.push({ action: 'write', collection, data: localData })
    this.scheduleFlush()       // 300ms 防抖批量 flush
  }

  // 读取：本地优先
  read<T>(collection: string, id: string): T | null {
    return uni.getStorageSync(`sync:${collection}:${id}`) || null
  }

  // 批量 flush：调用 syncData 云函数
  private async flush(): Promise<void> {
    if (this.syncing || this.queue.length === 0) return
    this.syncing = true
    const ops = this.queue.splice(0)
    try {
      const res = await wx.cloud.callFunction({
        name: 'syncData', data: { ops, lastSyncAt: this.lastSyncAt }
      })
      // 合并云端增量
      res.result.remoteChanges.forEach(c => this.applyRemote(c))
      this.lastSyncAt = res.result.serverTime
      // 标记已完成同步
      ops.forEach(op => {
        const key = `sync:${op.collection}:${op.data._id}`
        const d = uni.getStorageSync(key)
        if (d) uni.setStorageSync(key, { ...d, _synced: true })
      })
    } catch { this.queue.unshift(...ops) }  // 失败恢复
    finally { this.syncing = false }
  }

  // 300ms 防抖：多次写入合并为一次云端请求
  private scheduleFlush() {
    clearTimeout(this.flushTimer)
    this.flushTimer = setTimeout(() => this.flush(), 300)
  }
}

6.5 syncData 云函数实现

// cloudfunctions/syncData/index.js
const cloud = require('wx-server-sdk')
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })
const db = cloud.database(); const _ = db.command

exports.main = async (event, context) => {
  const { ops, lastSyncAt } = event
  const openid = cloud.getWXContext().OPENID

  // 1. 执行客户端提交的批量操作（upsert 模式）
  for (const op of ops) {
    const coll = db.collection(op.collection)
    if (op.action === 'write') {
      const { _id, ...data } = op.data
      await coll.doc(_id).set({
        data: { ...data, userId: openid, updatedAt: new Date() }
      }).catch(() => coll.add({ data: { _id, ...data, userId: openid, createdAt: new Date() } }))
    } else if (op.action === 'delete') {
      await coll.doc(op.data._id).remove()
    }
  }

  // 2. 返回上次同步后的云端增量变更
  const collections = ['favorites', 'notes', 'progress', 'quiz_records', 'daily_challenges']
  const remoteChanges = {}
  for (const name of collections) {
    const res = await db.collection(name)
      .where({ userId: openid, updatedAt: _.gt(new Date(lastSyncAt)) })
      .limit(200).get()
    if (res.data.length > 0) remoteChanges[name] = res.data
  }
  return { serverTime: new Date().toISOString(), remoteChanges }
}

8.1 全文搜索（预建扁平索引 + 300ms 防抖）

在 formula store 初始化时构建 flatIndex，预计算每条公式的 searchText（name + latex + note + detail 合并转小写），避免搜索时重复拼接。

// src/composables/useSearch.ts
export function useSearch() {
  const query = ref('')
  const debouncedQuery = ref('')
  const subjectFilter = ref('')
  const levelFilter = ref('')
  const sortBySection = ref(true)
  let timer: number

  const setQuery = (q: string) => {
    query.value = q
    clearTimeout(timer)
    timer = setTimeout(() => { debouncedQuery.value = q.trim().toLowerCase() }, 300)
  }

  const results = computed(() => {
    if (!debouncedQuery.value) return []
    const q = debouncedQuery.value
    const list: SearchResult[] = []
    const store = useFormulaStore()
    for (const item of store.flatIndex) {
      if (subjectFilter.value && !item.sectionId.startsWith(subjectFilter.value)) continue
      if (levelFilter.value && item.level !== levelFilter.value) continue
      if (item.searchText.includes(q)) {
        list.push({ sectionId: item.sectionId, sectionTitle: item.sectionTitle, formulaIndex: item.index })
      }
    }
    if (sortBySection.value) list.sort((a, b) => a.sectionId.localeCompare(b.sectionId) || a.formulaIndex - b.formulaIndex)
    return list
  })

  return { query, setQuery, results, subjectFilter, levelFilter, sortBySection, ... }
}

┌──────────┐ 开始 ┌──────────┐ 答完 ┌──────────┐ │ SETUP │ ────→ │ QUIZ │ ────→ │ RESULT │ │ 设置参数 │ │ 选择题模式 │ │ 成绩展示 │ └──────────┘ └──────────┘ └──────────┘ │ ↑ ↑ │ 开始闪卡 │ │ ├──────────────────┐│ │ │ ↓↓ │ │ ┌──────────┐ │ └──────────→│ FLASHCARD│────────────────┘ │ 闪卡模式 │ 完成 └──────────┘ 题库来源：全部公式 / 收藏夹 / 错题本 题目构建：shuffle → 取前 N → 随机抽 3 个错误选项 答题节奏：正确 800ms 自动下一题，错误 1800ms（留时间看解析）
// src/composables/usePractice.ts
export function usePractice() {
  const phase = ref<Phase>('setup')       // setup | quiz | flashcard | result
  const poolMode = ref<PoolMode>('all')   // all | favorites | mistakes
  const quizMode = ref<QuizMode>('mcq')   // mcq | flashcard
  const count = ref(10)
  const questions = ref<Question[]>([])
  const qIndex = ref(0);  const score = ref(0)

  const pool = computed(() => {
    if (poolMode.value === 'favorites') return /* 收藏筛选 */
    if (poolMode.value === 'mistakes')  return /* 错题筛选 */
    return allFormulas
  })

  const startQuiz = () => {
    const selected = shuffle(pool.value).slice(0, count.value)
    questions.value = buildMcqQuestions(selected)
    qIndex.value = 0; score.value = 0; phase.value = 'quiz'
  }

  const handleAnswer = (optIndex: number) => {
    const correct = questions.value[qIndex.value].options[optIndex].correct
    if (!correct) addMistake(q.sectionId, q.index)   // 写入错题本
    setTimeout(nextOrFinish, correct ? 800 : 1800)
  }

  return { phase, poolMode, quizMode, count, questions, qIndex, score, startQuiz, handleAnswer, ... }
}

8.4 学习进度追踪

// src/composables/useProgress.ts
export function useProgress() {
  const progress = ref<Record<string, number[]>>({})

  const markViewed = (sectionId: string, index: number) => {
    if (!progress.value[sectionId]) progress.value[sectionId] = []
    if (!progress.value[sectionId].includes(index)) {
      progress.value[sectionId].push(index)
      syncer.write('progress', { sectionId, viewedFormulas: progress.value[sectionId] })
    }
  }

  const getProgress = (sectionId: string, total: number) => {
    const viewed = progress.value[sectionId]?.length || 0
    return Math.round((viewed / total) * 100)
  }

  return { progress, markViewed, getProgress }
}

8.5 收藏系统

// src/composables/useFavorites.ts
export function useFavorites() {
  const favorites = ref<Set<string>>(new Set())
  const has = (sid: string, i: number) => favorites.value.has(`${sid}:${i}`)

  const toggle = async (sectionId: string, index: number) => {
    const key = `${sectionId}:${index}`
    const next = new Set(favorites.value)
    next.has(key) ? next.delete(key) : next.add(key)
    favorites.value = next
    await syncer.write('favorites', {
      _id: `${userId}_${sectionId}_${index}`,
      sectionId, formulaIndex: index, isDeleted: !next.has(key)
    })
  }

  return { favorites, toggle, has }
}

⚠️ 风险评估与应对策略

风险 1：Canvas 公式渲染性能问题

小程序 Canvas 渲染复杂公式可能出现卡顿。

应对：
  • LRU 缓存（200 条），命中率 > 80%，避免重复渲染
  • 预计算字符度量表，减少运行时 measureText 调用
  • 公式列表使用虚拟滚动，仅渲染可见区域
  • 渐进式渲染：简单公式优先，复杂公式延迟 100ms
  • 预渲染图片降级兜底
风险 2：数据同步冲突

多设备同时编辑笔记或收藏时可能出现冲突。

应对：
  • 采用"最后写入胜出"策略，简单场景足够
  • 收藏操作幂等，重复操作不影响结果
  • 笔记编辑使用时间戳，保留最新版本
  • 提供手动同步按钮，用户可主动触发同步
  • 本地优先策略，离线操作联网后自动同步
风险 3：微信审核不通过

小程序可能因类目选择、内容审核等原因不通过。

应对：
  • 提前阅读微信小程序审核规范
  • 选择"教育 > 在线教育"类目（不需要特殊资质）
  • 准备好隐私政策和用户协议
  • 避免敏感内容和违规功能
  • 预留 1-2 周缓冲时间应对审核反馈
风险 4：单人开发进度延期

单人开发可能因各种原因导致进度延迟。

应对：
  • 每周迭代，及时调整优先级
  • 优先实现核心功能，非核心可后续迭代

// V2.0 — src/data/types.ts 新增
export type Grade = 'university' | 'senior-high' | 'junior-high'

// V2.0 — src/data/registry.ts（公式注册表）
import universityFormulas from './formulas-university'
import seniorFormulas    from './formulas-senior'

export const GRADE_REGISTRY: Record<Grade, FormulaMap> = {
  'university':  universityFormulas,
  'senior-high': seniorFormulas,
  'junior-high': {} as FormulaMap,  // V3.0 填充
}

// V2.0 — src/stores/formulas.ts 调整
export const useFormulaStore = defineStore('formulas', () => {
  const currentGrade = ref<Grade>('university')
  const data = computed(() => GRADE_REGISTRY[currentGrade.value])
  const flatIndex = computed(() => buildFlatIndex(data.value))
  const switchGrade = (grade: Grade) => { currentGrade.value = grade }
  return { currentGrade, data, flatIndex, switchGrade }
})
